# 流程图绘制器

一个纯前端的流程图绘制器，只用 HTML / CSS / JavaScript 写成。双击 `index.html` 即可使用，不需要安装依赖，也不需要起服务器。

## 打开方式

两种方式，任选其一：

- 双击 [index.html](index.html)（源码版，便于修改）；
- 双击 [流程图绘制器.html](流程图绘制器.html)（单文件版，CSS 与脚本全部内联，方便直接发给别人）。改动源码后运行 `npm run build` 重新生成。

## 三个核心能力

### 1. 网格底纹可开关

顶部「网格底纹」按钮一键显示 / 隐藏；旁边可调网格间距（10/20/25/50，或在右侧面板自定义）与样式（方格 / 点阵）。网格随画布缩放移动，缩得过小会自动隐藏，避免糊成一片。

### 2. 组件与箭头自动吸附

四个开关相互独立，可自由组合：

| 开关 | 作用 |
| --- | --- |
| 吸附网格 | 拖动、缩放组件时对齐到网格（上/中/下三条线里挑位移最小的一条去贴网格，所以下边线也能吸附） |
| 智能参考线 | 与其他组件的边缘、中心对齐时自动吸附，并画出粉色参考线 |
| 箭头吸附 | 箭头端点吸附到最近组件的连接点（上下左右），命中时高亮 |

吸附优先级为「智能参考线 > 网格」。按住 `Alt` 拖动可临时关闭全部吸附，自由摆放。

组件被移动时，连在它身上的箭头会自动重新走线；箭头端点也可以拖到别的组件上重新连接。

关掉「箭头吸附」后，箭头端点可以停在**任意位置**（自由端点），不再强制连到组件上，也不会因为没吸附到组件而取消绘制；两种状态下都能正常画箭头，只是连续与否的区别。自由端点随时可以再拖到组件上变成连接，右侧面板的「端点连接」里也能直接切换（选「自由位置」即可脱离组件）。

### 3. 自定义组件尺寸

三种改尺寸的方式：

- 选中组件后拖动四周 8 个手柄；按住 `Shift` 或勾选「锁定宽高比」可等比缩放；
- 右侧面板直接输入宽高，或点 `140×64`、`200×100` 预设按钮；
- 点「适应文字」，让组件自动缩放到刚好放下文字。

把调好尺寸与样式的组件点「存为组件」，即可保存到左侧「自定义组件」栏反复复用（存放在浏览器本地，在其上右键可删除）。

### 4. 自定义模板

框选若干个组件（连同它们之间的箭头）后点「存为模板」，就能把这一整块存进左侧「我的模板」。之后点一下或拖到画布，整组组件与内部箭头会一起插入，相对位置保持不变。模板同样存放在浏览器本地，在其上右键可删除。

## 组件与箭头

内置 10 种图形：处理、起止、判断、数据、文档、数据库、准备、子流程、连接圆、纯文本。

箭头支持折线（直角）、直线、曲线三种走线，可在顶部或右侧切换；可设颜色、线宽、虚实、起止箭头，以及线上的标签文字（双击箭头即可编辑）。

几个和箭头相关的细节：

- **同一对组件之间可以连多根箭头**，同方向的会自动并排错开，不会叠成一条；
- **多条箭头之间有三种画法**（在箭头属性「双向箭头」里切换）：
  - **无**＝默认行为：同向多根自动错开，反向箭头自然重叠成一条两端带箭头的线；
  - **重合**＝合并成**一条双向箭头线**（两端各一个箭头，是一个整体）：选中、拖动拐点、删除都是整体操作，删一次就干净了；想拆开就选「分开」；
  - **分开**＝拆成两条并排的箭头，各自可以单独点选、单独删除；两条走线互不交叉——两端端口朝向相同时（比如都在顶部）做成一大一小的嵌套 U 形，端口相对时（一左一右）错成两条平行 Z 形，且目标组件往上拖或往下拖都保持不交叉；
  - 判定"是不是一对"只看是否用同一对端口，所以左边连一根、右边连一根这种不会凑成一对（也就不会被强行偏移导致错位）；
  - 三种状态可以互相切换：单向 →（重合）双向箭头线 →（分开）两条 →（重合）合并回去。

  「无」按钮只有在**双向关系是自动补出来的**时候才可用（点它会退回原来那根单向箭头）；如果两根都是你自己连的，说明你本来就想画双向，这时「无」是灰的——拆开请用「分开」，或者直接删掉其中一根。

## 多画板（标签页）

顶部标签栏可以同时开多个画板（点 `＋` 新建、双击标签改名、点 `×` 关闭，至少保留一个）。每个画板的内容、缩放位置、撤销历史互相独立，切换即时生效，并且会一起自动保存，下次打开还在。

左侧的两个示例模板有三种用法：**当前画板是空的**，点一下直接放进本页；**当前画板已有内容**，点击会新开一个画板放进去（不打扰你现在这张）；也可以直接把模板**拖到画布上**放进当前画板。从组件库或模板栏往外拖时，画布上会按**真实形状**显示落点预览（模板里每个组件都画成虚线轮廓，位置和大小就是松手后的结果），而不是只给一个外框。
- **折线的转折点可以自己摆**：选中折线后，中间那根直线上会出现一个粉色手柄，拖它就能改这根直线的位置；如果走线是「一个从侧面出、一个从上面进」这种混合走向，手柄在拐角上，拖开就会变成可自由摆放的 S 形拐点。不想改了就在箭头属性里点「重置折线」；
- **「尾线」设置**（画布设置里）控制箭头前后那段直线的最短长度，默认 16px。线越粗箭头越长，尾线太短会出现箭头压住转折点、看起来错位的情况，调大它即可。

## 面板收起 / 展开

左侧「组件库」和右侧「属性」面板都可以用面板上的箭头按钮收起，收起后只留一条窄边，按钮下方竖着写出面板名字（组件库 / 属性），画布自动变大。展开与收起带非线性缓动动画，且会记住状态，下次打开保持你上次的样子。

选中多个组件后可做左 / 中 / 右、上 / 中 / 下对齐，或横向、纵向等间距分布，也可调整叠放层级。

## 保存与导出

- 编辑内容自动保存在浏览器本地，下次打开自动恢复；
- 「保存 / 打开」用 JSON 文件存档与读取；
- 「导出」支持 SVG 矢量图、PNG 图片（2 倍分辨率）、JSON 数据；
- **「复制图片到剪贴板」**（导出菜单第一项，快捷键 `Ctrl+Shift+C`）：把当前画布渲染成 2 倍分辨率的 PNG 直接放进系统剪贴板，可以直接粘到聊天窗口、文档或邮件里，**不会在本地生成任何文件**。渲染全程在浏览器内存中完成；如果浏览器不允许写入图片剪贴板（少见），会提示你改用「导出 PNG 图片」。

```

```


## 说明与限制

- **折线会自动绕开挡在中间的组件**：默认走线若会穿过其他组件（包括连线两端自己的组件），会先微调中间那段，再尝试从上方/下方绕行，仍不行就在稀疏网格上做一次寻路（A*）找一条不通穿的正交路径；寻路时会让路径尽量靠向两端点的中间，走线看起来是对称的而不是贴着某一侧；只有四面全被堵死时才会退回直线。直线与曲线两种走线是按几何直连的，不做避让；

- 箭头端点可吸附到组件的四个连接点（上 / 右 / 下 / 左），也可以悬停在任意位置成为自由端点；暂不支持斜向连接点；
- 折线的可调范围有约束：中间那根直线只能在两个端口之间的走廊里移动，混合走向的拐点也只能拉出一定范围，避免拖出难以理解的走线；走廊窄到几乎没有余地时不再显示手柄，免得出现"拖不动"的手柄；
- 同一对端口上的两根箭头会各走一条通道，保证不会长距离重叠；但两个组件贴在一起时端口本身就挤，这种情况下两根线难免会有交叉——把组件拉开一点即可；
- 网格线宽会随缩放反向补偿，保持 1px 屏幕线宽，缩小画布也能看清；但当网格在屏幕上密于 6px 时会自动隐藏，避免糊成一片；
- 组件库里的默认尺寸都是 20 的倍数（默认网格间距），新建后四条边都能落在网格线上；
- 组件之间没有自动避让走线，箭头会按直角规则绕开组件，但可能与其它箭头交叉；
- PNG 导出依赖浏览器把内联 SVG 画到 canvas，主流浏览器（Chrome / Edge / Firefox / Safari）均可用；若受限可改用 SVG 导出；
- 控制台提供 `window.FD.__app` 调试入口（可访问 `store`、`state`、`render` 等），便于排查问题。
