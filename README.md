# 流程图绘制器

一个纯前端的流程图绘制器，只用 HTML / CSS / JavaScript 写成。双击 `index.html` 即可使用，不需要安装依赖，也不需要起服务器。

## 打开方式

两种方式，任选其一：

- 双击 [index.html](index.html)（源码版，便于修改）；
- 双击 [流程图绘制器.html](流程图绘制器.html)（单文件版，CSS 与脚本全部内联，方便直接发给别人）。改动源码后运行 `npm run build` 重新生成。

## 三个核心能力

### 1. 网格底纹可开关

顶部「网格底纹」按钮一键显示 / 隐藏；旁边可调网格间距（10/20/25/50，或在右侧面板自定义）与样式（方格 / 点阵）。网格随画布缩放移动，缩得过小会自动隐藏，避免糊成一片。

### 2. 组件与箭头自动吸附

四个开关相互独立，可自由组合：

| 开关 | 作用 |
| --- | --- |
| 吸附网格 | 拖动、缩放组件时对齐到网格（上/中/下三条线里挑位移最小的一条去贴网格，所以下边线也能吸附） |
| 智能参考线 | 与其他组件的边缘、中心对齐时自动吸附，并画出粉色参考线 |
| 箭头吸附 | 箭头端点吸附到最近组件的连接点（上下左右），命中时高亮 |

吸附优先级为「智能参考线 > 网格」。按住 `Alt` 拖动可临时关闭全部吸附，自由摆放。

组件被移动时，连在它身上的箭头会自动重新走线；箭头端点也可以拖到别的组件上重新连接。

关掉「箭头吸附」后，箭头端点可以停在**任意位置**（自由端点），不再强制连到组件上，也不会因为没吸附到组件而取消绘制；两种状态下都能正常画箭头，只是连续与否的区别。自由端点随时可以再拖到组件上变成连接，右侧面板的「端点连接」里也能直接切换（选「自由位置」即可脱离组件）。

### 3. 自定义组件尺寸

三种改尺寸的方式：

- 选中组件后拖动四周 8 个手柄；按住 `Shift` 或勾选「锁定宽高比」可等比缩放；
- 右侧面板直接输入宽高，或点 `140×64`、`200×100` 预设按钮；
- 点「适应文字」，让组件自动缩放到刚好放下文字。

把调好尺寸与样式的组件点「存为组件」，即可保存到左侧「自定义组件」栏反复复用（存放在浏览器本地，在其上右键可删除）。

### 4. 自定义模板

框选若干个组件（连同它们之间的箭头）后点「存为模板」，就能把这一整块存进左侧「我的模板」。之后点一下或拖到画布，整组组件与内部箭头会一起插入，相对位置保持不变。模板同样存放在浏览器本地，在其上右键可删除。

## 操作速查

### 鼠标

| 操作 | 效果 |
| --- | --- |
| 从左侧组件库拖入画布 / 单击 | 新建组件（拖入位置即落点） |
| 双击组件 | 编辑文字（`Ctrl+Enter` 或点击别处保存，`Esc` 取消） |

| 拖动箭头端点的圆点 | 把箭头改接到其他组件 |
| 把箭头端点拖到空白处 | 变成自由端点（不连组件） |
| 在空白处拖动 | 框选多个组件 |
| `Shift` + 点击 | 加选 / 减选 |
| 右键 | 组件、箭头、空白处各有对应菜单 |
| 滚轮 / `Shift` + 滚轮 | 上下 / 左右平移画布 |
| `Ctrl` + 滚轮 | 以光标为中心缩放 |
| 空格拖动 / 中键拖动 / 平移工具 | 平移画布 |

## 组件与箭头

内置 10 种图形：处理、起止、判断、数据、文档、数据库、准备、子流程、连接圆、纯文本。

箭头支持折线（直角）、直线、曲线三种走线，可在顶部或右侧切换；可设颜色、线宽、虚实、起止箭头，以及线上的标签文字（双击箭头即可编辑）。

选中多个组件后可做左 / 中 / 右、上 / 中 / 下对齐，或横向、纵向等间距分布，也可调整叠放层级。

## 保存与导出

- 编辑内容自动保存在浏览器本地，下次打开自动恢复；
- 「保存 / 打开」用 JSON 文件存档与读取；
- 「导出」支持 SVG 矢量图、PNG 图片（2 倍分辨率）、JSON 数据。

## 文件结构

```
index.html          页面结构
styles.css          样式（含深色主题）
src/geom.js         几何计算、形状库、文本排版（纯函数）
src/router.js       箭头路径计算（折线 / 直线 / 曲线 / 自环）
src/snap.js         吸附引擎（网格、参考线、端点）
src/store.js        数据模型、选中状态、撤销栈
src/view.js         SVG 渲染层（增量更新）
src/templates.js    示例模板
src/app.js          交互与界面装配
tests/              自测脚本
```

## 测试

```bash
npm test            # 全部
npm run test:unit   # 核心算法单测（几何 / 吸附 / 路由），不需要浏览器
npm run test:dom    # 无头浏览器端到端自测，需要本机装有 Chrome 或 Edge
```

覆盖范围：所有形状的轮廓交点、三种走线路径的合法性（含「折线不穿过组件」）、参考线与网格的吸附优先级、缩放吸附、端点吸附的边界情况，以及浏览器中真实渲染与拖拽交互（框选、吸附、缩放、连线、右键菜单、撤销重做、导入导出、深色主题等）。

## 说明与限制

- 箭头端点可吸附到组件的四个连接点（上 / 右 / 下 / 左），也可以悬停在任意位置成为自由端点；暂不支持斜向连接点；
- 网格线宽会随缩放反向补偿，保持 1px 屏幕线宽，缩小画布也能看清；但当网格在屏幕上密于 6px 时会自动隐藏，避免糊成一片；
- 组件库里的默认尺寸都是 20 的倍数（默认网格间距），新建后四条边都能落在网格线上；
- 组件之间没有自动避让走线，箭头会按直角规则绕开组件，但可能与其它箭头交叉；
- PNG 导出依赖浏览器把内联 SVG 画到 canvas，主流浏览器（Chrome / Edge / Firefox / Safari）均可用；若受限可改用 SVG 导出；
- 控制台提供 `window.FD.__app` 调试入口（可访问 `store`、`state`、`render` 等），便于排查问题。
